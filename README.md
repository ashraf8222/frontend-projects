# Frontend Projects

A collection of frontend projects built while learning and practicing **HTML, CSS, JavaScript, and Tailwind CSS**.

This repository contains small projects, UI experiments, and practical implementations created during my frontend development journey.

## Technologies

* HTML5
* CSS3
* JavaScript
* Tailwind CSS

## Repository Structure

Each project is maintained in its own directory:

```text
frontend-projects/
│
├── project-1/
├── project-2/
├── project-3/
├── ...
│
└── README.md
```

Projects are added continuously as I learn and practice new frontend concepts.

## Concepts Practiced

Depending on the project, this repository covers concepts such as:

* HTML structure
* CSS layouts and responsive design
* Flexbox and Grid
* Tailwind CSS
* JavaScript fundamentals
* DOM manipulation
* Event handling
* Browser APIs
* Local storage
* UI interactions
* Game logic

## Purpose

The goal of this repository is to learn frontend development through **consistent hands-on practice and project building**.

Instead of keeping practice code scattered across different locations, projects are organized here as a growing record of my frontend development journey.
